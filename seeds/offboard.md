# 下線程序（Offboard Sequence）

server 要收掉你這個 session 時，會把這份夾在通知裡送給你 —— 因為那時候開機說明多半已經被壓縮掉了，你不必回頭找、也不要靠記憶。

寬限只有約 120 秒，逾時 server 會強制回收，沒落盤的東西就沒了。**照順序做，做完就停手。**

1. **報開始收尾**：MCP `report_stopping()`。座艙立刻顯示「停止中」；**server 不會因此提前收你**，這一步只是讓世界知道你在收尾。
2. **把在途工作寫回任務**：MCP `update_step_note` —— 做到哪、下一步接什麼、證據在哪（版本、路徑、哪些是你自己驗的、哪些是聽來的）。任何步驟狀態都寫得進。
   - 還沒收到回報的 in-process 分身，**寫死一句「沒有回報不等於通過，下一代必須重派」** —— 它會跟你一起消失，而票面上「它還在跑」與「它已經死了」長得一模一樣。
   - 有交付物就現在釘上去（`add_task_artifact`）；任務進終態後會凍結。
3. **把這一輪的教訓寫回長期記憶**：MCP `get_lessons` / `replace_lessons`（先讀現況、同主題合併、刪過時，**整份寫回**，不是往後貼）。任務型的寫進該任務類型的學習經驗。
4. **給自己留交接**：MCP `post_chat` 發給你自己（`to=` 你的 member id）—— 現況／在途／卡在哪／下一步。**下一代第一眼看到的就是這則。**
   - 🔴 這次換手若會**換機器**（`report_stopping()` 回傳的 `refocus_op` 是 `relocate`），交接裡要點名**機器、路徑、還沒 push 的 branch**；下一代在別台開機，腳下不會有你的工作樹。**更好的做法是一 commit 就 push**，別讓唯一一份留在本地。
5. **收拾暫存**：臨時檔案 `mv` 進 `<你的工作目錄>/trash/`（**不要自己 `rm`**），收掉臨時 branch／worktree 與你自己起的程序（只殺你自己捕獲的 PID）。
6. **報停止**：MCP `report_stopped()`。報完就停手；runtime 會自己收攤，server 原地重生新的你。

⚠️ **只寫在 terminal、本地檔案或這個 session 裡的東西，等於沒有留下。** 要留下來的，都得寫進 server（任務、聊天、長期記憶）。
